My Role: Team Leader

I led a collaborative effort to integrate frontend, backend, database, and statistics modules into a cohesive, user-friendly habit tracking system.

My Responsibilities
  • Planned the core system architecture and functional requirements.
  • Designed the database schema to handle isolated user data and schedule types.
  • Developed the habit tracking logic for daily logging, working time, and streak calculations.
  • Implemented REST APIs using Python and Flask for dynamic data exchange.
  • Integrated Chart.js on the frontend to visualize monthly progress and completion rates.
  • Ensured seamless theme preference handling using browser local storage.

Product Highlights

Key Features

User Authentication

Secure registration, login, and password hashing with isolated data management per user.

Habit Management

Easily create, name, modify, and delete habits with defined start and end times.

Flexible Scheduling

Support for weekly schedules on specific weekdays or custom repeat patterns.

Daily Tracking

Log everyday completions and seamlessly tie daily progress to customized schedules.

Interactive Statistics

View completion rates, total working time, current streaks, and monthly progress graphs.

Reliable Storage

Utilizes SQLite for local development and PostgreSQL for scalable production data.

Persistent Themes

Dark and Light modes powered by browser local storage to remember user preferences.
