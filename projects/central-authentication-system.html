Responsibilities

The service owns the account lifecycle.

Registration

Central user registration with email OTP verification and password creation.

Email OTP Verification

Sends six-digit OTPs through the configured Brevo-compatible Email API.

Password Management

Creates hashed passwords, supports forgot password, and completes password reset flows.

Login & Sessions

Verifies credentials and maintains authenticated Flask sessions.

Website Management

Maintains websites and user-to-website access relationships.

My Websites

Provides the authenticated website directory associated with user_websites and websites.

Email Integration

Brevo-compatible Email API

Signup OTP and password-reset OTP are sent using the configured HTTP email service. The current default endpoint is:

https://api.brevo.com/v3/smtp/email
EMAIL_API_KEY
EMAIL_API_URL
EMAIL_FROM
EMAIL_FROM_NAME

EMAIL_API_KEY authenticates the request. EMAIL_API_URL selects the endpoint. EMAIL_FROM and EMAIL_FROM_NAME identify the sender. No real credentials are exposed.

Security Behavior

Implemented authentication protections

  • Werkzeug password hashing and verification
  • Hashed OTP storage
  • OTP expiration and consumption
  • 60-second OTP cooldown
  • 5 attempts within 5 minutes login rate limit
  • HTTPOnly, Secure, SameSite=Lax session cookies
  • Generic invalid-login response
  • Render deployment with HTTPS production expectation
