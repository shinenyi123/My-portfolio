Project Overview

Student record management in a web interface

The application accepts student data from an uploaded Excel file, stores the records in SQLite, and displays them in a simple dashboard view. Users can filter the rows by class, gender, and age before viewing or exporting the results.

Problem

Manual handling of student records in spreadsheets was time-consuming and made it harder to inspect and organize data consistently.

Solution

I built a Flask-based workflow that reads Excel input, stores records in SQLite, and provides a basic interface for filtering and exporting data as Excel files.
